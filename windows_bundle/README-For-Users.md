## Stop

Use **Stop CRKN OCR Tool** from the Start menu when you are done for the day.

<img width="1916" height="1115" alt="image" src="https://github.com/user-attachments/assets/d016b562-0dd1-4006-8337-4e6c7f97f1bf" />


## If Something Looks Stuck

Close the browser tab, run **Stop CRKN OCR Tool**, and start **CRKN OCR Tool** again from the desktop.

If it still does not work, send support the latest files from:

```text
C:\ProgramData\CRKN OCR Tool\logs
```
