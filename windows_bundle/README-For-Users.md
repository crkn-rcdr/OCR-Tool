# CRKN OCR Tool

## Start

1. Double-click **CRKN OCR Tool** on the desktop.
2. Wait for the browser page to open.
3. Choose an input image/folder and an output folder.
4. Choose the language.
5. Turn **pre process** and **post process** on or off.
6. Click **Run**.

## Stop

Use **Stop CRKN OCR Tool** from the Start menu when you are done for the day.

## If Something Looks Stuck

Close the browser tab and start **CRKN OCR Tool** again from the desktop.

If it still does not work, send support the latest files from:

```text
C:\ProgramData\CRKN OCR Tool\logs
```
